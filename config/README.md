# config
Все про конфигурацию запуска и dto хранения и работы с параметрами
- config - конфиг, который будет использоваться, если не переопределить дефолтный путь до него
- config_manager - глобальное dto конфига. Также способно отдавать сконфигурированное api до модели (если не хочешь класть openrouter api key в config, то есть поддержка env OPENROUTER_API_KEY)
