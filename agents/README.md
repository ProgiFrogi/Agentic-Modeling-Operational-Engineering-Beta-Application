# agents
Тут хранятся агенты
- supervisor - оркестрирует работу всех агентов
- coder - агент-кодер, ему приходит запрос на создание кода, он его пишет, после чего код проверяется (сначала быстро с помощью проверки AST, потом с помощью выполнения), в случае, если есть ошибка в коде, происходит fallback, ошибка передается кодеру вместе с прошлой версией кода и его просят поправить его
- trainer - пишет код и исполняет для тренировки модели и получения сразу же качества. Является оберткой над агентов кодера (coder)
- data_worker - агент-датааналитик. Составляет план для анализа данных. Является оберткой над агентов кодера (coder)
- validator - валидирует результат, смотрит только на результаты. Нужно чтобы были в нужном виде (после вызова supervisor еще делает фазу решения нужно ли заканчивать или что делать на основе динамики результатов)
- prompts/ - папка с промптами
