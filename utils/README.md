# utils
Утилитовые классы, DTO
- benchmark - Benchmark, MetricsCalculator, которые хранят результаты метрик и вычисляют их
- data_downloader - KaggleDataDownloader - загрузка информации о соревновании (если не дана уже в папке)
- guardrails - InputValidator проверяет входные параметры агента регуляркой, CodeSafetyChecker ограничивает код через черный список импортов и функций
- json_utils - достает json из ответа модели, если он был обернут как-то
- logger - создать логера и логировать
- session_manager - управление сессией, а имено файлами которые создаются во время работы модели и просто пайплайна
